## 저장소에 추가하는 방법

저장소 루트에 `homecoming` 폴더 전체를 업로드합니다.

```text
POINT-lab0.github.io/
├─ index.html
├─ images/
└─ homecoming/
   ├─ index.html
   ├─ style.css
   └─ README.md
```

GitHub Pages 배포 후 다음 주소로 접근할 수 있습니다.

```text
https://interaction.postech.ac.kr/homecoming/
```

행사 정보는 `homecoming/index.html`에서 직접 수정합니다.
